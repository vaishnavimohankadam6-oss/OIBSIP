# Oasis Infobyte Security Analyst Internship

Welcome to my cybersecurity project portfolio for the Oasis Infobyte Internship Program.

## About This Repository

This repository contains my internship tasks, practical exercises, security assessments, research reports, and documentation completed as part of my Security Analyst learning journey.

## Objectives

- Understand fundamental cybersecurity concepts.
- Practice network scanning and security analysis in authorized lab environments.
- Learn about firewalls, vulnerabilities, network traffic, and SQL injection.
- Develop practical security documentation and reporting skills.
- Improve technical skills through hands-on exercises.

## Internship Track

**Domain:** Cyber Security / Security Analyst

Each task will be organized in its own folder according to the internship guidelines.

## Ethical and Safe Practice

All practical security testing will be conducted only on systems and lab environments that I own or have explicit permission to test.

This repository is intended for educational purposes and responsible cybersecurity learning.
